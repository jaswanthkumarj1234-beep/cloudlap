# Easy File Transfer (Bluetooth)

Send files between two Windows computers with Bluetooth. No internet needed.
Big buttons and plain steps, made for people who just want it to work.

## Download
[**Click here to download EasyFileTransfer.zip**](https://github.com/jaswanthkumarj1234-beep/cloudlap/raw/main/BluetoothTransfer/EasyFileTransfer.zip)

## Use
1. Download the zip, right-click it, choose **Extract All**.
2. Double-click **EasyFileTransfer** (the file that looks like a gear).
   If Windows says "Windows protected your PC", click **More info**, then **Run anyway**.
3. Copy the same file to the other computer (pen drive) and open it there too.
4. First time only: click **1. Connect the two computers** on both.
5. Then use **2. SEND files** on one and **3. RECEIVE files** on the other.

It uses the Bluetooth transfer tool already built into Windows.
Both computers need Bluetooth turned on. Bluetooth is slow, so big files take a while.
