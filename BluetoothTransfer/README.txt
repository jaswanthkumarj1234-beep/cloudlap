EASY FILE TRANSFER (BLUETOOTH)
=============================

What it does
  Helps you move files between two Windows computers using Bluetooth.
  No internet is needed.

How to install (on BOTH computers)
  1. Copy this program to the computer, for example
     onto the Desktop. Use a pen drive for the first copy.
  2. Double-click "EasyFileTransfer".

How to use
  First time only:  click "1. Connect the two computers" and follow the steps.
  To send files:    click "2. SEND files".
  To receive files: click "3. RECEIVE files" (do this on the other computer).

Problems?
  - Make sure Bluetooth is turned ON on both computers.
  - Keep the computers close together (about 1-2 meters).
  - Bluetooth is slow. Large files can take a long time.
  - If a computer has no Bluetooth, a small Bluetooth USB adapter can be added.
